# What Is the Pollinations Model Intelligence Registry?

The Pollinations Model Intelligence Registry is a small, standalone Python toolkit for keeping track of how AI models perform when tested through Pollinations.

Think of it as a **notebook and comparison workbench for AI models**. Instead of relying on model names, marketing claims, or one successful response, it helps you save test results, ask models the same questions, compare outcomes, and track changes in published model information.

## What can it help you do?

- Keep a local record of model tests.
- Check whether a model can respond through the service.
- Evaluate answers against a starter set of repeatable benchmark questions.
- See which model actually handled a request.
- Compare saved results while keeping small sample sizes visible.
- Save dated model-catalog snapshots and compare what changed.
- Use an interactive menu instead of remembering every command.

## What it does not do

- It does not run large language models locally.
- It does not automatically test every model.
- It does not guarantee that a model is free or accepts a Quest-only key.
- It does not claim that a small benchmark is a definitive intelligence ranking.
- It does not upload your local databases automatically.
- It does not require integration with an AI agent or another project.

## Is it safe to explore?

Most features are offline and use local files. Live testing is deliberately separate: each run sends one question, requires explicit typed confirmation, and may consume earned Quest Pollen. Preview mode lets you inspect a proposed test without making a request or reading credentials.

## Who is it for?

It is useful for developers, AI enthusiasts, and researchers who want a more organized way to observe model behavior instead of relying on guesswork.

**The main idea:** record what happened, distinguish a successful connection from a good answer, and make comparisons based on evidence rather than assumptions.
